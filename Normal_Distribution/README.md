# 📊 Normal Distribution Visualizer

An interactive Streamlit app that shows how the **mean** and **standard deviation** change the shape of a normal distribution. Move the sliders to shift the curve left or right, or make it wider or narrower, and compare it with the standard normal curve (mean = 0, SD = 1).

🔗 **[Try the live app](https://traditional-ml-algorithms-dhjrj9nkkcwtuaytv8r2tj.streamlit.app/)**

**Built with:** Python, Streamlit, Plotly, NumPy, SciPy
